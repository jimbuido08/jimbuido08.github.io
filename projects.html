  • Build a shield instead of reacting to a breach.

    [Python] Password Strength Classifier

    Move from "looks hard" to "scores hard" — classify weak passwords before a breach exposes them.

    Open on Kaggle Information sheet
    Challenge
    Password security was long treated as length + complexity. Brute-force and modern cracking have made that no longer enough — can a model classify whether a password is actually weak before a breach exposes it?
    Technical edge
    Three classifiers (Logistic Regression, SVM, Naïve Bayes) trained on the Bhavik Bansal Kaggle corpus and grid-searched per algorithm. Naïve Bayes is not an obvious pick for text-shaped input — keeping it in the comparison, rather than reaching for a transformer, is the explicit constraint-then-test move.
    Win
    Evaluation uses the full classification report (accuracy, precision, recall, F1) and a confusion matrix — not a single headline number. Pick-the-best-by-F1, not pick-the-best-by-acc, is the discipline that distinguishes the notebook from a tutorial.

  • Retain is cheaper than acquire.

    [R] Bank Customer Churn Prediction

    Demographics and account activity, with geography added as a spatial variable — does it shift the picture?

    Open on Kaggle Information sheet
    Challenge
    Banks usually model churn from demographics + account activity. This project keeps those — and asks whether adding geography (country) as a spatial variable changes the picture.
    Technical edge
    Four classifiers (Logistic Regression, SVM, Random Forest, Naïve Bayes) on the Gaurav Topre Kaggle dataset. customer_id was excluded from feature variables with an explicit rationale — the kind of modelling hygiene employers notice in interviews more than in portfolios. Evaluation is three-way: coefficient plot, confusion matrix, ROC curve.
    Win
    Breadth-and-discipline rather than a headline accuracy: multiple models compared with paired metrics (coefficient plot + CM + ROC), and a deliberate feature-set decision rather than a default one.
